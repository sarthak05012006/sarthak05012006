## 👋 Hi, I'm Sarthak

I'm a developer who likes working where **code meets the physical world**: sensors, servos, microcontrollers and models that actually *do* something.

> **If I can imagine it, I want to try building it.**

```text
💡 IDEA  →  🧠 LOGIC  →  💻 CODE  →  🔌 HARDWARE  →  🤖 WORKING SYSTEM
```
